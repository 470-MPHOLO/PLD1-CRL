Loops

A loop repeats instructions. One pass through the body is an iteration. A counter is a variable that tracks how many times the loop has run.

  • WHILE: checks the condition before each pass, so it may run zero times.
  • REPEAT UNTIL: checks after each pass, so it always runs at least once. It stops when the condition becomes TRUE.
  • FOR: use when you know how many passes you need. STEP -1 counts backwards.
total = 0
counter = 1
WHILE counter <= 20
  total = total + counter
  counter = counter + 1
END WHILE

Infinite loop: the condition never becomes false (usually a forgotten increment). Sentinel value: a special input (such as -1) that means "stop". Always check count > 0 before dividing to find an average.

Arrays

An array stores several values of the same type under one name. Each value has an index. With 0-based indexing, an array of size 5 has indexes 0 to 4. Using index 5 is out of bounds.

DECLARE nums[5]
nums[0] = 7
FOR i FROM 0 TO 4
  DISPLAY nums[i]
END FOR

Patterns to remember

  • Running total: set total = 0 BEFORE the loop, add inside, use after.
  • Largest value: start with largest = nums[0], then compare with > and update value and position together. Use < for the smallest.
  • Linear search: start found = FALSE, set it TRUE when matched, and report AFTER the loop.
  • Even or odd: n MOD 2 = 0 means even. MOD gives the remainder; DIV gives the whole-number quotient.
